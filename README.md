# Alley Android downloads

Signed customer APKs for **Alley Parent** and the native **Alley Child** companion
are distributed through this repository's GitHub Releases.

- Install `parent.apk` on the parent's Android phone.
- Install `child.apk` on the child's Android phone.
- Read the selected release's version and minimum Android details before installing.
- Pair with a fresh QR or six-character code generated inside your Parent account.

Each release contains `SHA256SUMS.txt` and `release-manifest.json` so you can check
file integrity and app metadata. APKs are release assets; application source,
Admin APKs, private signing keys and credentials are not included in this repository.

Downloading does not activate paid features. Contact
[@mrx1505 on Telegram](https://t.me/mrx1505) for pricing, account-bound feature
access, installation help and updates.

Earlier development builds used Android Debug signing and cannot be updated in
place with the production release key. Contact support before migrating a phone
that already has a paired development installation.
